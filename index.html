VBA 코드 활용 실습 교재

엑셀 매크로 기초부터 매출 데이터 취합 · 피벗 · HTML 대시보드 자동화까지, 코드는 버튼 하나로 복사해서 바로 사용하세요.

실습 준비 사항

  1. 엑셀 리본 메뉴에서 [파일] > [옵션] > [리본 사용자 지정] > 오른쪽 목록에서 '개발 도구' 체크 → 확인
  2. VBA 코드를 입력할 때는 [개발 도구] 탭 > [Visual Basic] (단축키 Alt + F11)을 눌러 VBA 편집기(VBE)를 엽니다.
  3. 매크로가 포함된 파일은 반드시 '.xlsm' (매크로 사용 통합 문서) 형식으로 저장해야 합니다.
  4. 코드를 실행하려면 VBE 창에서 커서를 코드 안에 두고 F5 키를 누르거나, 실습 3에서 배우는 '버튼'을 사용합니다.
💡 좌측 "자료 다운로드"에서 예제 엑셀 파일 3종과 Word 실습교재를 미리 받아두세요.

실습 1. 기초 실습 - A1 셀에 'Hello' 자동 입력하기

가장 기본적인 VBA 문법인 '셀에 값 쓰기'를 실습합니다. 매크로를 실행하면 현재 활성화된 시트의 A1 셀에 'Hello'라는 문자열이 자동으로 입력됩니다.

실습 절차

  1. Alt + F11 을 눌러 VBA 편집기를 엽니다.
  2. 왼쪽 프로젝트 창에서 통합 문서를 선택한 뒤, 상단 메뉴 [삽입] > [모듈]을 클릭합니다.
  3. 생성된 모듈 창에 아래 코드를 입력합니다.
Sub Hello_Input()
    ' A열 1행(A1 셀)에 'Hello' 문자열을 입력하는 매크로
    Range("A1").Value = "Hello"
End Sub
  1. 커서를 코드 안에 두고 F5 키를 눌러 실행합니다.
  2. 엑셀 시트로 돌아가 A1 셀에 'Hello'가 입력되었는지 확인합니다.

코드 설명

  • Sub ~ End Sub : 하나의 매크로(프로시저)의 시작과 끝을 의미합니다.
  • Range("A1") : 워크시트의 A1 셀을 가리키는 객체입니다.
  • Value : 셀에 들어갈 값을 지정하는 속성입니다.
💡 Range("A1") 대신 Cells(1, 1) 로도 동일하게 표현할 수 있습니다. (Cells(행, 열) 순서)

실습 2. 글자 색깔과 폰트 바꾸기

실습 1에서 만든 코드를 확장하여, 셀에 값을 입력한 후 폰트 종류·크기·굵기·글자 색을 함께 지정하는 방법을 익힙니다.

Sub Hello_Format()
    Dim tgt As Range
    Set tgt = Range("A1")

    ' 1) 값 입력
    tgt.Value = "Hello"

    ' 2) 폰트 이름과 크기 지정
    tgt.Font.Name = "맑은 고딕"
    tgt.Font.Size = 20

    ' 3) 굵게, 기울임 지정
    tgt.Font.Bold = True
    tgt.Font.Italic = False

    ' 4) 글자 색깔 지정 (RGB 방식: 빨강)
    tgt.Font.Color = RGB(255, 0, 0)

    ' 5) 셀 배경색 지정 (선택 사항: 연한 노랑)
    tgt.Interior.Color = RGB(255, 242, 204)
End Sub

코드 설명

  • Font.Name : 글꼴을 지정합니다. (예: "맑은 고딕", "굴림", "Arial")
  • Font.Size : 글자 크기(포인트)를 지정합니다.
  • Font.Bold / Font.Italic : True/False로 굵게·기울임 여부를 설정합니다.
  • Font.Color = RGB(R, G, B) : 0~255 사이의 값으로 색을 표현합니다. RGB(255,0,0)은 빨강입니다.
  • Interior.Color : 셀의 배경(채우기) 색을 지정합니다.
💡 RGB 대신 vbRed, vbBlue 같은 VBA 내장 색상 상수를 사용할 수도 있습니다. 예: tgt.Font.Color = vbRed

실습 3. 매크로를 버튼으로 만들어 실행하기

매번 F5 키를 누르거나 매크로 목록에서 찾지 않고, 시트에 버튼을 배치하여 클릭 한 번으로 매크로를 실행하는 방법을 익힙니다.

실습 절차

  1. [개발 도구] 탭 > [삽입] > '양식 컨트롤' 영역에서 '단추(양식 컨트롤)' 아이콘을 선택합니다.
  2. 워크시트에서 버튼을 삽입할 위치를 드래그하여 버튼을 그립니다.
  3. '매크로 지정' 창이 자동으로 뜨면, 앞서 만든 Hello_Format 매크로를 선택하고 [확인]을 클릭합니다.
  4. 버튼을 마우스 오른쪽 클릭 > [텍스트 편집]으로 버튼 이름을 '실행' 등으로 바꿉니다.
  5. 버튼을 클릭하여 매크로가 정상 실행되는지 확인합니다.
💡 이미 만든 버튼에 다른 매크로를 연결하고 싶다면, 버튼 위에서 마우스 오른쪽 클릭 > [매크로 지정]에서 다시 선택할 수 있습니다.
💡 그림/도형(SmartArt 등)에도 동일한 방식으로 마우스 오른쪽 클릭 > [매크로 지정]을 적용하면 버튼처럼 사용할 수 있습니다.

참고: 버튼 클릭 시 실행될 매크로 예시

Sub ResetAndRun()
    ' 버튼 클릭 시 A1을 초기화하고 다시 서식을 적용하는 예시
    Range("A1").ClearContents
    Range("A1").ClearFormats
    Call Hello_Format   ' 실습 2에서 만든 매크로 호출
End Sub
💡 Call 키워드로 다른 Sub 프로시저를 호출하면, 매크로를 재사용하고 코드를 모듈화할 수 있습니다.

실습 4. 지점별 매출 파일 3개 취합하기

실제 업무에서 가장 많이 쓰이는 '여러 엑셀 파일을 하나로 합치기' 실습입니다. 식품회사의 지점별 판매사원 매출 현황 예제 파일 3개를 제공하며, 이를 VBA로 자동 취합합니다.

제공 예제 파일

  • 서울지점_판매현황.xlsx (김민준, 이서연, 박도윤)
  • 부산지점_판매현황.xlsx (최지훈, 정하윤)
  • 대구지점_판매현황.xlsx (강예준, 윤소율, 임지호)

각 파일은 '매출현황' 시트에 아래와 같은 동일한 열 구조를 갖고 있습니다. (취급 제품: 오리온 초코파이, 농심 신라면, 롯데 빼빼로, 해태 홈런볼, 오뚜기 진라면)

날짜지점담당자제품명판매수량단가매출액
2026-09-01서울지점김민준농심 신라면324,200134,400

실습 절차

  1. 새 통합 문서를 만들고 '취합_전체매출.xlsm' 이름으로 매크로 사용 통합 문서로 저장합니다.
  2. 예제 파일 3개를 취합 파일과 동일한 폴더 하위의 예제파일 폴더에 위치시킵니다.
  3. Alt + F11 > 모듈 삽입 후 아래 코드를 입력합니다.
Sub Consolidate_Branch_Sales()
    ' ==========================================================
    ' 지정한 폴더 안의 지점별 판매현황(*.xlsx) 파일을 모두 읽어
    ' 현재 통합 문서의 "취합데이터" 시트에 한 번에 모으는 매크로
    ' ==========================================================
    Dim FolderPath As String
    Dim FileName As String
    Dim wbSrc As Workbook
    Dim wsSrc As Worksheet
    Dim wsDst As Worksheet
    Dim lastRowSrc As Long
    Dim lastRowDst As Long

    ' 1) 원본 파일들이 들어있는 폴더 경로 (환경에 맞게 수정)
    FolderPath = ThisWorkbook.Path & "\예제파일\"

    ' 2) 취합 결과를 넣을 시트 준비 (있으면 초기화, 없으면 새로 생성)
    On Error Resume Next
    Set wsDst = ThisWorkbook.Worksheets("취합데이터")
    On Error GoTo 0
    If wsDst Is Nothing Then
        Set wsDst = ThisWorkbook.Worksheets.Add
        wsDst.Name = "취합데이터"
    Else
        wsDst.Cells.Clear
    End If

    ' 3) 헤더 작성
    wsDst.Range("A1:G1").Value = Array("날짜", "지점", "담당자", "제품명", "판매수량", "단가", "매출액")
    wsDst.Range("A1:G1").Font.Bold = True

    Application.ScreenUpdating = False

    ' 4) 폴더 내 모든 xlsx 파일 순회
    FileName = Dir(FolderPath & "*.xlsx")
    Do While FileName <> ""
        Set wbSrc = Workbooks.Open(FolderPath & FileName, ReadOnly:=True)
        Set wsSrc = wbSrc.Worksheets("매출현황")

        lastRowSrc = wsSrc.Cells(wsSrc.Rows.Count, "A").End(xlUp).Row
        lastRowDst = wsDst.Cells(wsDst.Rows.Count, "A").End(xlUp).Row

        If lastRowSrc >= 2 Then
            wsSrc.Range("A2:G" & lastRowSrc).Copy _
                Destination:=wsDst.Cells(lastRowDst + 1, 1)
        End If

        wbSrc.Close SaveChanges:=False
        FileName = Dir   ' 다음 파일명으로 이동
    Loop

    wsDst.Columns("A:G").AutoFit
    wsDst.Range("A1").Select

    Application.ScreenUpdating = True
    MsgBox "취합이 완료되었습니다!", vbInformation
End Sub

코드 설명

  • Dir(FolderPath & "*.xlsx") : 폴더 안의 xlsx 파일명을 하나씩 가져옵니다. 반복문 안에서 인수 없이 Dir을 다시 호출하면 다음 파일명을 반환합니다.
  • Workbooks.Open ... ReadOnly:=True : 원본 파일을 읽기 전용으로 열어 실수로 원본이 수정되는 것을 방지합니다.
  • End(xlUp) : 해당 열의 마지막 데이터가 있는 행을 찾는 코드로, 표 범위가 매번 달라도 자동으로 대응합니다.
  • wbSrc.Close SaveChanges:=False : 원본 파일은 저장하지 않고 닫습니다.
💡 만약 시트 이름이 파일마다 다르다면, wsSrc = wbSrc.Worksheets("매출현황") 부분을 wbSrc.Worksheets(1) (첫 번째 시트) 로 바꾸면 시트 이름에 상관없이 동작합니다.

실습 5. 취합된 자료로 피벗 테이블 만들기

실습 4에서 만든 '취합데이터' 시트를 원본으로 하여, 지점 × 제품별 매출 합계를 보여주는 피벗 테이블을 VBA로 자동 생성합니다.

Sub Create_Pivot_From_Consolidated()
    Dim wsData As Worksheet
    Dim wsPivot As Worksheet
    Dim pCache As PivotCache
    Dim pTable As PivotTable
    Dim srcRange As Range
    Dim lastRow As Long, lastCol As Long

    Set wsData = ThisWorkbook.Worksheets("취합데이터")

    ' 1) 원본 데이터 범위 자동 설정
    lastRow = wsData.Cells(wsData.Rows.Count, "A").End(xlUp).Row
    lastCol = wsData.Cells(1, wsData.Columns.Count).End(xlToLeft).Column
    Set srcRange = wsData.Range(wsData.Cells(1, 1), wsData.Cells(lastRow, lastCol))

    ' 2) 기존 "피벗분석" 시트가 있으면 삭제 후 재생성
    Application.DisplayAlerts = False
    On Error Resume Next
    ThisWorkbook.Worksheets("피벗분석").Delete
    On Error GoTo 0
    Application.DisplayAlerts = True

    Set wsPivot = ThisWorkbook.Worksheets.Add
    wsPivot.Name = "피벗분석"

    ' 3) 피벗 캐시 및 피벗 테이블 생성
    Set pCache = ThisWorkbook.PivotCaches.Create( _
        SourceType:=xlDatabase, _
        SourceData:=srcRange)

    Set pTable = pCache.CreatePivotTable( _
        TableDestination:=wsPivot.Range("A3"), _
        TableName:="pt_지점제품매출")

    ' 4) 행/열/값 필드 배치
    With pTable
        .PivotFields("지점").Orientation = xlRowField
        .PivotFields("제품명").Orientation = xlColumnField

        With .PivotFields("매출액")
            .Orientation = xlDataField
            .Function = xlSum
            .NumberFormat = "#,##0"
            .Caption = "매출액 합계"
        End With

        With .PivotFields("판매수량")
            .Orientation = xlDataField
            .Function = xlSum
            .NumberFormat = "#,##0"
            .Caption = "판매수량 합계"
        End With
    End With

    wsPivot.Range("A1").Value = "지점 x 제품별 매출 피벗 분석"
    wsPivot.Range("A1").Font.Bold = True
    wsPivot.Range("A1").Font.Size = 14

    MsgBox "피벗 테이블이 생성되었습니다!", vbInformation
End Sub

코드 설명

  • PivotCaches.Create : 원본 데이터를 메모리에 캐시로 저장하여 피벗 테이블이 참조할 수 있게 합니다.
  • xlRowField / xlColumnField / xlDataField : 필드를 각각 행, 열, 값(데이터) 영역에 배치하는 설정입니다.
  • Function = xlSum : 값 영역에서 집계 방식을 '합계'로 지정합니다. (xlCount, xlAverage 등도 가능)
  • 담당자별로 더 세분화하고 싶다면 .PivotFields("담당자").Orientation = xlRowField 를 추가하면 됩니다.
💡 실습 전 [개발 도구] > [매크로 보안]에서 매크로 실행이 허용되어 있는지 확인하세요. 또한 이 매크로는 실습 4의 결과(취합데이터 시트)가 먼저 만들어져 있어야 합니다.

실습 6. 피벗 결과를 BI 대시보드(HTML)로 만들기

실습 5에서 만든 피벗 테이블 데이터를 읽어와, 검색·정렬 기능과 KPI 카드, 막대그래프가 포함된 반응형 BI 대시보드(.html)를 자동 생성하는 매크로입니다. 참조 설정 없이 ADODB.Stream으로 UTF-8 저장을 처리하여 한글 깨짐을 방지하고, 생성 후 기본 브라우저로 자동 실행됩니다.

주요 기능

  • HTML 파일을 UTF-8로 저장하여 한글 깨짐 방지
  • 지점명 검색 상자 (실시간 필터링)
  • 지점별 합계 기준 오름차순/내림차순 정렬 및 초기화 버튼
  • 총매출·분석 지점 수·분석 제품 수 KPI 카드
  • 지점별 총매출 막대그래프 + 표 셀 안의 제품별 매출 막대그래프
  • PC/모바일 반응형 레이아웃 (미디어 쿼리 적용)
  • 생성이 끝나면 기본 브라우저로 자동 실행
💡 이 매크로를 사용하려면 실습 5에서 만든 "피벗분석" 시트와 "pt_지점제품매출" 피벗 테이블(행: 지점, 열: 제품명, 값: 매출액 합계)이 먼저 준비되어 있어야 합니다.

'
' 대상 워크시트 : 피벗분석

' 행 필드 : 지점
' 열 필드 : 제품명
' 값 필드 : 매출액 합계
'
' 주요 기능
' 1. HTML 파일을 UTF-8로 저장
' 2. 한글 깨짐 방지
' 3. 지점명 검색
' 4. 지점별 합계 기준 정렬
' 5. KPI 카드 생성
' 6. 지점별 총매출 막대그래프
' 7. 제품별 매출 셀 막대그래프
' 8. 반응형 웹 화면
' 9. 생성 후 기본 브라우저 자동 실행

Public Sub Export_Pivot_To_BI_Dashboard()

    Const SHEET_NAME As String = "피벗분석"
    Const PIVOT_NAME As String = "pt_지점제품매출"

'============================================================
' 피벗테이블 값 안전하게 가져오기
' 데이터가 없거나 GetPivotData 오류 발생 시 0 반환
'============================================================
Private Function GetPivotValueSafe( _
    ByVal pTable As PivotTable, _
    ByVal dataFieldName As String, _
    ByVal rowFieldName As String, _
    ByVal rowItemName As String, _
    ByVal columnFieldName As String, _
    ByVal columnItemName As String) As Double

    Dim resultValue As Variant

    On Error GoTo ValueError

    resultValue = pTable.GetPivotData( _
                    dataFieldName, _
                    rowFieldName, rowItemName, _
                    columnFieldName, columnItemName).Value

    If IsError(resultValue) Then
        GetPivotValueSafe = 0
    ElseIf IsNumeric(resultValue) Then
        GetPivotValueSafe = CDbl(resultValue)
    Else
        GetPivotValueSafe = 0
    End If

    Exit Function

ValueError:

    GetPivotValueSafe = 0
    Err.Clear

End Function


'============================================================
' 화면에 표시되는 피벗 항목만 Collection으로 반환
' 총합계, 빈 항목, 숨김 항목 제외
'============================================================
Private Function GetVisiblePivotItems( _
    ByVal targetField As PivotField) As Collection

    Dim result As New Collection
    Dim pItem As PivotItem
    Dim itemName As String
    Dim isVisible As Boolean

    For Each pItem In targetField.PivotItems

        itemName = Trim$(CStr(pItem.Name))
        isVisible = True

        On Error Resume Next
        isVisible = pItem.Visible
        On Error GoTo 0

        If isVisible Then

            If Len(itemName) > 0 _
               And itemName <> "(blank)" _
               And itemName <> "(공백)" _
               And itemName <> "총합계" _
               And LCase$(itemName) <> "grand total" Then

                result.Add itemName

            End If

        End If

    Next pItem

    Set GetVisiblePivotItems = result

End Function


'============================================================
' HTML 특수문자 변환
' 지점명 또는 제품명에 &, <, >, 따옴표가 있어도 오류 방지
'============================================================
Private Function HtmlEncode(ByVal sourceText As String) As String

    Dim encodedText As String

    encodedText = sourceText
    encodedText = Replace(encodedText, "&", "&amp;")
    encodedText = Replace(encodedText, "<", "&lt;")
    encodedText = Replace(encodedText, ">", "&gt;")
    encodedText = Replace(encodedText, """", "&quot;")
    encodedText = Replace(encodedText, "'", "&#39;")

    HtmlEncode = encodedText

End Function


'============================================================
' ADODB.Stream을 이용한 UTF-8 파일 저장
' 참조 설정 없이 CreateObject 방식으로 실행
'============================================================
Private Sub SaveTextAsUTF8( _
    ByVal textContent As String, _
    ByVal filePath As String)

    Dim streamObject As Object

    On Error GoTo SaveError

    Set streamObject = CreateObject("ADODB.Stream")

    With streamObject

        '2 = 텍스트 데이터
        .Type = 2

        'UTF-8 문자 인코딩
        .Charset = "utf-8"

        .Open

        '생성된 HTML 전체 입력
        .WriteText textContent

        '2 = 기존 파일이 있으면 덮어쓰기
        .SaveToFile filePath, 2

        .Close

    End With

    Set streamObject = Nothing

    Exit Sub

SaveError:

    If Not streamObject Is Nothing Then
        On Error Resume Next
        streamObject.Close
        Set streamObject = Nothing
        On Error GoTo 0
    End If

    Err.Raise Err.Number, "SaveTextAsUTF8", Err.Description

End Sub

코드 설명

  • GetVisiblePivotItems : 피벗 필드에서 화면에 실제로 표시되는 항목만 Collection으로 모아, 숨김 항목·빈 항목·총합계 행을 제외하고 대시보드에 반영합니다.
  • GetPivotValueSafe : GetPivotData 호출 시 데이터가 없어 오류가 나더라도 0을 반환하도록 예외 처리하여 매크로가 중단되지 않게 합니다.
  • HtmlEncode : 지점명·제품명에 &, <, >, 따옴표가 포함되어 있어도 HTML이 깨지지 않도록 특수문자를 변환합니다.
  • SaveTextAsUTF8 (ADODB.Stream) : Charset을 "utf-8"로 지정해 텍스트를 저장하는 방식으로, 참조 설정 없이 CreateObject만으로 동작하며 한글 인코딩 문제를 근본적으로 방지합니다.
  • KPI 카드 / 막대그래프 : 실제 차트 객체가 아니라 값 비율만큼 너비를 갖는 <div> 막대를 CSS로 그려 표현한 것입니다.
  • filterTable() / sortTable() / resetTable() : 자바스크립트로 구현된 검색, 정렬, 초기화 기능으로 별도 서버 없이 브라우저에서만 동작합니다.

[작성 형식]
- Word 문서 기준 약 8~12페이지 분량
- 문체는 과장되지 않은 전문적인 경영기획 보고서 형식
- 결론을 먼저 제시하고 근거 수치를 뒤에 설명
- 긴 문장보다 짧고 명확한 문장 사용
- 주요 수치는 표로 정리
- 표마다 2~3문장의 해석을 추가
- 확인된 사실, 데이터 기반 해석, 추가 검증이 필요한 가설을 명확히 구분
- 모든 전략에 실행 담당, 일정, KPI를 포함
- 불필요한 이론 설명은 제외
- 제공되지 않은 수치나 사실은 임의로 만들지 말 것
- 추가 데이터가 필요한 부분은 문서 마지막에 "추가 확보 필요 데이터"로 정리

[시각화 제안]
문서에 다음 차트를 삽입할 위치와 차트 제목을 표시해줘.
- 지점별 매출 비교 세로 막대그래프
- 제품별 매출 및 판매수량 조합 차트
- 날짜별 매출 추이 꺾은선그래프
- 지점 × 제품 매출 히트맵
- 담당자별 매출 비교 막대그래프
- 매출 성장 시나리오 비교 차트

실제 차트 생성이 어렵다면, 차트가 들어갈 위치에 [차트 삽입: 차트명] 형식으로 표시해줘.

마지막에는 다음 내용을 별도 박스로 요약해줘.
- 지금 즉시 시작할 과제 3개
- 추가 의사결정이 필요한 사항 3개
- 추가로 확보해야 할 데이터 5개

프롬프트 설계 포인트

  • 역할 지정 : "사업기획팀장 겸 데이터 분석가"로 역할을 명확히 지정해 실행계획 중심의 출력을 유도합니다.
  • 데이터 검증 단계 명시 : 매출액 = 판매수량 × 단가 검증, 결측/중복 확인 등을 먼저 요청해 데이터 신뢰도를 높입니다.
  • 사실과 가정의 구분 : "5일 데이터를 분기 전체로 일반화하지 말 것", "추가 검증이 필요한 가설로만 제시" 등으로 과장된 결론을 방지합니다.
  • 표 + 해석 구조 : 모든 수치는 표로 정리하고, 표마다 2~3문장의 해석을 추가하도록 요청해 보고서 가독성을 높입니다.
  • 실행계획 구체화 : 전략마다 담당 조직·시작 시점·KPI·목표값·위험요인·대응방안까지 표로 요구해 바로 실행 가능한 수준의 결과물을 얻습니다.
  • 차트 위치 지정 : 실제 차트 생성이 어려운 환경에서도 "[차트 삽입: 차트명]" 형식으로 표시하게 하여, 이후 파워포인트나 엑셀에서 시각화를 채워 넣기 쉽게 합니다.

증상원인 및 해결 방법
매크로가 저장되지 않고 사라짐파일을 '.xlsx'로 저장했기 때문입니다. '다른 이름으로 저장' > 파일 형식을 'Excel 매크로 사용 통합 문서(.xlsm)'로 선택하세요.
'매크로를 사용할 수 없음' 경고가 뜸[파일] > [옵션] > [보안 센터] > [매크로 설정]에서 '모든 매크로 포함(알림 표시)' 이상으로 설정하고, 파일을 신뢰할 수 있는 위치에 두세요.
Worksheets("매출현황") 오류 (구독을 찾을 수 없음)원본 파일의 시트 이름이 다르거나 오타가 있는 경우입니다. 시트명을 확인하거나 Worksheets(1)로 바꿔 첫 번째 시트를 사용하세요.
PivotCaches.Create 오류원본 데이터 범위에 빈 열/행이 섞여 있거나, 헤더가 중복된 경우 발생합니다. 데이터 범위와 헤더를 다시 확인하세요.
